# Contributing

Bug reports and ideas go into [issues](https://github.com/MichaelPrutkow/anki-mcp/issues). For a bug,
the output of "check my Anki setup" helps most.

## Development

```bash
uv sync
uv run pytest                                       # against a fake AnkiConnect, no Anki needed
ANKI_LIVE=1 uv run pytest tests/test_live_anki.py   # read-only smoke test against your real Anki
uvx ruff check src tests server.py && uvx ruff format --check src tests server.py
claude --plugin-dir .                               # try the plugin in Claude Code
claude plugin eval .                                # with vs. without the plugin, mocked tools
```

The evals in `evals/` run against mocked tools in `evals/mocks/anki`. `_tools.json` there is the
server's tool list; regenerate it when a tool's name, description or parameters change.

## Dependencies

After changing dependencies, regenerate `requirements.txt`. The launcher installs from it when uv
is missing and only Anki's own Python is there:

```bash
uv export --frozen --no-dev --no-emit-project --format requirements-txt --quiet > requirements.txt
```

`tests/test_packaging.py` fails when it is out of date.

## MathJax names

`src/anki_mcp/mathjax_names.py` lists the macros and environments MathJax knows in Anki (Anki 25.9 ships
MathJax 3.2.2 as tex-chtml-full, without textmacros). When Anki updates MathJax, save this script outside the
plugin folder as `mathjax_names.js` and run it:

```bash
npm install --prefix /tmp/mj mathjax-full@3.2.2
node mathjax_names.js /tmp/mj/node_modules/mathjax-full > src/anki_mcp/mathjax_names.py
```

```js
const js = process.argv[2] + "/js";
const { AllPackages } = require(js + "/input/tex/AllPackages.js");
const { ConfigurationHandler } = require(js + "/input/tex/Configuration.js");
const { MapHandler } = require(js + "/input/tex/MapHandler.js");
const version = require(process.argv[2] + "/package.json").version;

const packages = AllPackages.filter((p) => p !== "textmacros");
const macros = new Set();
const environments = new Set();
for (const name of packages) {
  const handler = ConfigurationHandler.get(name).handler;
  for (const [kind, target] of [["macro", macros], ["delimiter", macros], ["environment", environments]]) {
    for (const mapName of handler[kind] || []) {
      const map = MapHandler.getMap(mapName);
      if (map && map.map instanceof Map) {
        for (const key of map.map.keys()) {
          if (kind !== "delimiter") target.add(key);
          else if (key.startsWith("\\")) target.add(key.slice(1));
        }
      }
    }
  }
}
// Characters TeX treats as macros on their own (\, \; \{ ...) are not words and never need checking.
const words = (set) => [...set].filter((n) => /^[a-zA-Z]+\*?$/.test(n)).sort();
const block = (names) => {
  const lines = [];
  let line = "";
  for (const n of names) {
    if (line.length + n.length + 1 > 110) {
      lines.push(line.trim());
      line = "";
    }
    line += " " + n;
  }
  return [...lines, line.trim()].map((l) => "    " + l).join("\n");
};
console.log(`"""Macro and environment names MathJax ${version} knows in Anki (tex-chtml-full without textmacros).

Generated by the script in CONTRIBUTING.md. Do not edit by hand.
"""

_MACROS = """
${block(words(macros))}
"""

_ENVIRONMENTS = """
${block(words(environments))}
"""

MACROS = frozenset(_MACROS.split())
ENVIRONMENTS = frozenset(_ENVIRONMENTS.split())`);
```

It lives here and not as a file because the plugin directory does not accept JavaScript files in a plugin.

## Releases

1. Raise the version in `.claude-plugin/plugin.json` and `pyproject.toml` (a test checks that they
   agree), then run `uv lock`.
2. Add the version to `CHANGELOG.md`.
3. Commit, tag it as `anki--v<version>` and push the tag.
