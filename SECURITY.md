# Security

Please report security problems by email to
[michael.prutkow@tum.de](mailto:michael.prutkow@tum.de), not in a public issue.

Only the newest version gets fixes.

What the plugin can reach on your computer: AnkiConnect, image and PDF files you name by path,
Markdown files it writes when asked, and its own folders `~/.anki-mcp` and `~/Pictures/Anki MCP`.
Ways around these limits are what I most want to hear about, for example a way to make it open
other files or change notes it did not create without asking.
